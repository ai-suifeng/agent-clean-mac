怎么用

扫描、看清楚、移到废纸篓

整个过程不到一分钟。扫描只读取文件大小，不会打开或修改任何文件；清理前你能看到每一项的路径和说明。

01 · 扫描

每个工具是轨道上的一颗星

扫到哪个工具，哪颗星就亮起来，发现的数据流进中间的计数。卸载过的工具会被单独标出来。

02 · 看清楚

每一项都写着「删了会怎样」

内环是工具，外环是具体条目，颜色代表风险等级。可以按条目或按分组勾选、反选，悬停就能看到说明。

03 · 清理

移到废纸篓，随时能恢复

AgentSweep 不直接删除任何东西。每次清理都会记下原来的位置，在「清理记录」里可以放回去。清空废纸篓后，空间才真正释放。

功能

为 AI 编程工具量身定做

通用清理工具只知道文件夹大，AgentSweep 知道它是哪个工具的、是干什么的。

认识每个工具的目录

Claude Code、Codex、Cursor、Kimi Code、ZCode 等 14 种工具，每条路径都有规则和中文说明。

旧会话先导出再删

浏览 Claude Code 和 Codex 的全部会话，按项目和时间筛选，一键导出成 Markdown 留档。

数据库只压缩不删除

Cursor、Codex 的聊天数据库永远不删。退出对应工具后，先备份再压缩，如实显示能收回多少空间。

找出卸载残留

App 早就删了、数据还留着的工具，比如 Trae、Windsurf，会被单独找出来。

新工具也能跟上

规则是一个 JSON 文件，放进本地规则文件夹就能新增工具。还会列出可能未收录的 AI 工具文件夹提醒你。

自动更新

每天检查一次 GitHub 上的新版本，安装前校验签名。新工具的规则会随着版本更新送到你手上。

常见问题

你可能想问

真的免费吗？

是的。AgentSweep 以 MIT 协议开源，没有付费版、没有广告，也不收集任何使用数据。唯一的网络请求是检查 GitHub 上有没有新版本。

会不会误删我的东西？

AgentSweep 只处理规则里写明的路径；登录凭证、配置、技能和插件都受保护，聊天数据库只压缩不删除。所有清理都是移到废纸篓，在「清理记录」里可以放回去。

为什么清理后磁盘空间没有变化？

文件在废纸篓里仍然占空间。确认工具都运行正常后，清空废纸篓，空间才会真正释放。

为什么提示「无法验证开发者」？

安装包还没有经过苹果公证。第一次打开时右键点应用选「打开」，或运行 xattr -dr com.apple.quarantine /Applications/AgentSweep.app，之后就不会再提示。代码全部开源，也可以自己从源码构建。

怎么更新？

0.2.0 及以后的版本每天自动检查一次更新，有新版本会提示你一键安装，安装前会校验更新包的签名。可以在「设置」里关闭自动检查，或开启自动下载安装。0.1.0 需要手动下载一次新版。

我用的工具不在支持列表里怎么办？

在「规则库」页面能看到可能未收录的 AI 工具文件夹。可以按 README 的示例写一条规则放进本地规则文件夹，也欢迎到 GitHub 提交规则，下个版本就能送到所有人手上。

怎么卸载 AgentSweep？

把应用拖进废纸篓即可。如果想删干净，再删掉 ~/Library/Application Support/AgentSweep（清理记录和数据库备份）。
